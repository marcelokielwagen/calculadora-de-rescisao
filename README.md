# Calculadora de Rescisão

Calcula o valor exato de saída de um emprego (CLT) em cada tipo de rescisão: sem justa causa, pedido de demissão, acordo (art. 484-A), rescisão indireta, fim de contrato por prazo, contrato encerrado antes do fim e justa causa.
Inclui INSS e Imposto de Renda com as tabelas de **2026** (isenção até R$ 5.000 pela Lei 15.270/2025), 13º, férias, aviso prévio proporcional, FGTS e multa.

Abra em: https://marcelokielwagen.github.io/calculadora-de-rescisao/

É uma estimativa para conferir o termo de rescisão. Nada digitado sai do navegador.
Estudo independente, sem vínculo com o governo. Desenvolvido por Claude Sonnet 5.5.

## Arquivos
- `index.html` — a página
- `calculo.js` — o motor de cálculo e as tabelas (um só lugar para atualizar em 2027)
- `testes.js` — conferência dos cálculos (`node testes.js`)
